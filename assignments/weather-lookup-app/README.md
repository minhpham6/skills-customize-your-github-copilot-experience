# 📘 Assignment: Weather Lookup App

## 🎯 Objective

Build a simple Python program that connects to a public weather API, retrieves current weather information for a city, and displays it in a student-friendly format.

## 📝 Tasks

### 🛠️ Create a Basic Weather Request

#### Description
Use Python to request weather data from an API and print the result.

#### Requirements
Completed program should:

- Use the requests library to call a weather API
- Accept a city name from the user
- Display the city name and current temperature
- Handle missing or invalid input gracefully

### 🛠️ Format the Output

#### Description
Make the weather information easier to read by formatting the response clearly.

#### Requirements
Completed program should:

- Show the weather description and temperature in a readable message
- Include a simple error message if the request fails
- Keep the program easy to run from the terminal

### 🛠️ Add a Small Improvement

#### Description
Add one extra feature to make the app more useful.

#### Requirements
Completed program should:

- Add one improvement such as a favorite city list, unit selection, or a simple history feature
- Keep the program simple and easy to understand
